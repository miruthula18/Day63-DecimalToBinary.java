# Day 63 - Decimal to Binary Conversion

Today I learned how to convert a decimal number into binary using Java.

### Concepts Used

* `Scanner`
* `while` loop
* Modulus operator `%`
* Division operator `/`
* String manipulation

### Example

**Input:** `10`
**Output:** `1010`

### What I Learned

I learned how to repeatedly divide a decimal number by 2 and build its binary representation.
